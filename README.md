## ✨ Visão geral

A aplicação reúne os fluxos administrativos do FIXA e disponibiliza uma interface integrada para dados operacionais, gestão de pessoas, eventos e interação com o assistente Manu.

## 🚀 Funcionalidades

- Autenticação e recuperação de senha
- Gestão de instituições, unidades e usuários
- Gestão de equipes, técnicos, turnos e aptidões
- Calendário e gestão de eventos
- Perfil e preferências de aparência
- Dashboard com indicadores operacionais
- Consulta de desempenho dos técnicos
- Assistente de inteligência artificial Manu
- Tabelas, gráficos e respostas em Markdown
- Upload e visualização de imagens
- Rotas protegidas e validação de formulários
- Recursos de acessibilidade e navegação por teclado

## 🧰 Tecnologias

| Área | Tecnologias |
| --- | --- |
| **Interface** | React, TypeScript e Mantine |
| **Build** | Vite e Node.js |
| **Navegação** | React Router |
| **Comunicação** | Axios |
| **Visualização** | Recharts e React Markdown |
| **Analytics** | Databricks AI/BI Client |
| **Qualidade** | ESLint e Prettier |
